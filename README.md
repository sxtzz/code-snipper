# cleanse

> turn messy data into clean insights. unstructured → structured → actionable.

## About

**cleanse** is a data curation and analysis tool that takes raw, unstructured data (CSV, JSON, text, logs) and transforms it into clean, structured, analyzable insights.

No cloud. No data leaving your machine. Just you and your data.

## Features

- Upload CSV, JSON, TSV, TXT files
- Paste raw data directly
- Fill missing values
- Remove duplicates
- Normalize text
- Detect outliers
- Export as CSV or PDF

## Built With

- HTML/CSS
- Vue.js 2
- pdf-lib

## Usage

1. Open `index.html` in your browser
2. Upload a file or paste raw data
3. Use the cleaning buttons
4. Export your clean data
